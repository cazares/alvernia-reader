## web-reader-core

**Web reader (web/src/app.js + web/src/index.html) — boot, geo-gate, book resolution, page rendering/prefetch, song navigation, search/browse drawer, offline precache, localStorage persistence, relay-follower UI surfaces**

The reader half of the SignoVivo web PWA served at signovivo.com and also bundled into the native iOS shell via file:// WKWebView. It boots behind a blank-white geo-gate, resolves which songbook to show (private "standard" Del Rio manual vs public "hymns-4" Sión floor) via native injection, persisted localStorage, live IP-geo (X-Hymnal header), or a director-code unlock, then renders page images, offers jump-by-number/search/browse navigation, and background-precaches the book(s) for fully-offline use during Mass.

## web-sync-relay

**web/src/app.js — SYNC half: relay WebSocket follow, seq/stale-director logic, director-code unlock, geo-book gating, go-live UI, native-bridge sync events, fleet check-in**

The sync half of the SignoVivo web PWA (signovivo.com) lets follower devices mirror a music director's page live during Mass via a Cloudflare Worker relay (WebSocket push with /state HTTP polling fallback), while the same file also serves as the shared bundle inside the native iPad shell where sync arrives over the ReactNativeWebView bridge instead. It resolves WHICH songbook to show (geo-IP X-Hymnal header, persisted svGeoBook, native injection, director snapshot, or a server-validated director-code unlock of the private "standard" manual), guards a blank-white geo-gate so the wrong book never flashes, and reports device readiness to a fleet dashboard.

### State & invariants

- JS role state machine: roleRef ∈ {off, director, follower} plus explicitTransmitterRef overlay (roleRef 'off' + explicitTransmitterRef=true = transmitter-only 'director' to the web UI). roleGenerationRef (PdfReaderApp.tsx:96) is bumped at every role-entry path; every become* captures it at entry and bails after each await if superseded.
- Swift role state machine: currentRole ∈ {off, director, follower}; resetGeneration UUID (DirectorSyncModule.swift:78) invalidates every timer/async continuation on resetTransport; follower sub-states: searching → connecting (pendingInvitePeer set) → connected (connectedDirectorPeer set) → self-directed after 10s without a director.
- AsyncStorage keys (native shell): sv_bc (breadcrumb, PdfReaderApp.tsx:124), sv_devid (197–202), sv_fleet_label / sv_fleet_skip (209–238), director_access_code (STORED_CODE_KEY:66), sv.sync.lastRole, sv.sync.lastDirectorAt, sv.book.active, sv.book.lastPage.<bookId> (offlineBooks.ts:84–97). offlineBooks.ts also defines legacy keys sv.onboarding.*, sv.standard.accessName, sv.mode used only by dead clearAllBookState.
- Invariant: a follower must never re-broadcast — stopDirectorHeartbeat called on becomeFollower (376) and DIRECTOR_CONFLICT (836); relay heartbeat tick itself re-checks roleRef/explicitTransmitterRef (353).
- Invariant: lastDirectorSnapshotRef is null until a director page actually arrives over the mesh (107); it is THE guard that keeps geo/set-book and bridge-ready resync from ripping a fresh-boot follower off its own page (891, 572–576).
- Invariant: role-restore bootstrap runs exactly once per session (didBootstrapRef:117,762) — the mesh effect's deps can change identity and re-run the effect, and a re-run must not re-mint a director.
- Invariant: book+page always travel in ONE sync-event ({type:'page',page,book}); a separate set-book before a page event is forbidden (raced at await switchBook; documented at 581–583, 641–646, 806–811, 930–935).
- Invariant (Swift): a director sends NO snapshot until currentPageNumber is non-nil (222–239) — an empty bookId would be coerced to hymns-4 by JS bookFromSync and yank a standard-book follower.
- Invariant: director restore window is 24h (DIRECTOR_RESTORE_WINDOW_MS:64) and requires the stored code; exit-director and soft reset remove lastDirectorAt + director_access_code so relaunch does not auto-restore.
- Relay seq invariant: seq must be monotonic across app restarts — implemented as max(seq+1, Date.now()) wall-clock milliseconds (directorRelaySync.js:57–61); ts is separate wall-clock SECONDS (120). Worker freshness window RELAY_LIVE_MAX_AGE_S=90 is fed by the 12s relay heartbeat (PdfReaderApp.tsx:327–330).
- Mesh caps: 8KB max inbound control payload, 7 followers per MCSession, 2 sessions max (14 followers); MCPeerID displayName ≤50 chars + 6-char UUID suffix; session code normalized uppercase alnum ≤12 chars (Swift 1545–1547).
- Director-conflict total order: token = zero-padded 20-digit microsecond timestamp + '-' + UUID, compared lexicographically; strictly higher token wins; equal impossible (1549–1556).
- Documents/WebBundle (peer-pushed) always beats the shipped Bundle WebBundle in resolveBundleUri (711–724); install validates per-file sizes vs manifest and index.html > 200 bytes before the swap (1004–1019 Swift).
- Build-number lockstep invariant: version.json.buildNumber == pbxproj CURRENT_PROJECT_VERSION == Info.plist CFBundleVersion == app.json ios.buildNumber == __SIGNO_VINO_NATIVE_BUNDLE_VERSION == web badge == Swift currentBundleVersion used for bundle_offer comparisons; enforced by bump-build.mjs + e2e/native-entrypoint.test.mjs; violated builds break peer bundle-update version comparisons.
- Book-scoped director-code invariant: Sión public code 1234567890 valid ONLY on hymns-4; baked standard codes valid ONLY on standard; committed director-codes.json is intentionally empty (real numbers baked from gitignored director-codes.private.json by release.sh at archive time).
